# OpenRoad

OpenRoad is an experimental CLI for turning product plans, PRDs, and feature lists into structured implementation roadmaps for OpenSpec-driven agent workflows.

The goal is to make `roadmap.md` a first-class coordination layer between product thinking, OpenSpec proposals, and coding agents.

```text
PRD / feature list
        ↓
roadmap.md
        ↓
OpenSpec-friendly changes
        ↓
agent implementation
        ↓
review, merge, checkoff and on to the next action
